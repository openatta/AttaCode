两个改过名的，和改名的理由

这两个名字曾经只说中了一半 —— 名字不是不方便，是会误导。

approval→ask

它现在同时装权限审批和模型提问（AskUserQuestion）。 而键位层早就叫 ask.confirm / ask.prev / ask.next-request —— 新名字是去跟已有的词汇会合，不是另造一个。

completion→picker

它现在装 slash 补全、@ 文件提及、/resume 会话选择器三种。 PickerKind::Session 这个变体本身就是"completion 这个名字撑不住了"的信号。

已废止：Z/R/S 坐标

v3 那套 Z0.R1 / Z2.R2.S2 已经退役。它被废掉不是因为难看，是因为 它已经在说谎：面向测试的两处曾把任务清单标成 Z1（实际 Z1.R1）、把提问框标成 Z2（实际 Z2.R2.S2）—— 要数三层才写得对的东西，写着写着就不对了。而且它和代码是两套词汇（代码里从来只用语义路径）， 中间插一个区域就得全体重编号。代码路径没有这些毛病：写错了 grep 不到、编译不过。
